## 2. Система типов

### 2.1 Общая характеристика

Статическая / динамическая, строгая / слабая, явная / выводимая, номинальная / структурная.

### 2.2 Примитивные типы

| Тип       | Размер   | Диапазон / описание         | Пример литерала |
|-----------|----------|-----------------------------|-----------------|
| `int`     | 64 бит   | −2⁶³ .. 2⁶³−1              | `42`            |
| `float`   | 64 бит   | IEEE 754 double             | `3.14`          |
| `bool`    | 1 байт   | `true` / `false`            | `true`          |
| `char`    | 4 байта  | Unicode code point          | `'ж'`           |
| `string`  | динамич. | UTF-8 последовательность    | `"привет"`      |
| `void`    | —        | Отсутствие значения         | —               |

### 2.3 Составные типы

```
# Кортеж

# Запись / структура

# Перечисление
type Color = Red | Green | Blue

# Алгебраический тип (сумма + произведение)
type Result<T, E> = Ok(T) | Err(E)
```

### 2.5 Приведение типов

Явное / неявное, безопасное / небезопасное.

```
x: Int8  = 10

```

## 3. Лексика

### 3.1 Кодировка

Исходный файл в UTF-8. Строки и идентификаторы могут содержать Unicode.

### 3.2 Пробельные символы

Пробел, табуляция, `\n`, `\r\n` — все считаются разделителями. Имеет ли отступ синтаксическое значение (как в Python)?

### 3.3 Комментарии

```
// однострочный

/* многострочный
   комментарий */

/// документационный комментарий (попадает в doc-gen)
```

### 3.4 Идентификаторы

Правило: `[a-zA-Z_][a-zA-Z0-9_]*`. Unicode-идентификаторы: да / нет.  
Соглашения: `camelCase` для переменных, `PascalCase` для типов, `SCREAMING_SNAKE` для констант.

### 3.5 Литералы

```
# Целые числа
42       # десятичный
0xFF     # шестнадцатеричный
0b1010   # двоичный
0o123    # октальный
0z4YZ    # 32-ричный
1_000_000  # разделитель разрядов

# Числа с плавающей точкой
3.14
1.0e-9

# Строки
"обычная строка\n"
"""
многострочная
строка
"""
r"сырая строка\nбез эскейпов"

# Символы
'A'   '\n'   '\u{1F600}'
```

## 5. Выражения и операторы

### 5.1 Арифметика

| Оператор | Описание          | Пример       |
|----------|-------------------|--------------|
| `+`      | Сложение          | `a + b`      |
| `-`      | Вычитание         | `a - b`      |
| `*`      | Умножение         | `a * b`      |
| `/`      | Деление (float)   | `a / b`      |
| `//`     | Целочисл. деление | `a // b`     |
| `%`      | Остаток           | `a % b`      |
| `**`     | Возведение в степ.| `2 ** 10`    |

### 5.2 Сравнение

```
a == b    # равенство по значению
a != b    # неравенство
a < b
a <= b
a > b
a >= b
a is b    # равенство по ссылке / идентичность (если применимо)
```

> **Важно:** `==` сравнивает значения, `is` — идентичность объекта.

### 5.3 Логические операторы

```
a and b   # ленивое И
a or b    # ленивое ИЛИ
not a     # отрицание
```

### 5.4 Присваивание

```
x := 10           # простое присваивание
x += 5            # составное присваивание (+= -= *= /= //= %= **=)
a, b := b, a       # деструктурирующее присваивание (своп)
{ name, age } := person   # деструктуризация записи
[head, ...tail] := list   # деструктуризация списка
```

> Присваивание является **выражением** / **инструкцией** (выбрать).  
> Повторное присваивание в `let`-переменных: запрещено / разрешено с `mut`.

### 5.5 Битовые операторы

```
a & b     # AND
a | b     # OR
a ^ b     # XOR
~a        # NOT
a << n    # сдвиг влево
a >> n    # сдвиг вправо
```

### 5.6 Приоритет операторов (от высшего к низшему)

| Уровень | Операторы                    |
|---------|------------------------------|
| 1       | `()` вызов, `[]` индексация  |
| 2       | унарные `-` `not` `~`        |
| 3       | `**`                         |
| 4       | `*` `/` `//` `%`             |
| 5       | `+` `-`                      |
| 6       | `<<` `>>`                    |
| 7       | `&`                          |
| 8       | `^`                          |
| 9       | `\|`                         |
| 10      | `==` `!=` `<` `<=` `>` `>=` |
| 11      | `and`                        |
| 12      | `or`                         |
| 13      | `=` `+=` `-=` …             |

## 6. Управляющие конструкции

### 6.1 Условный оператор

```
if x > 0 {
    print("положительное")
} else if x < 0 {
    print("отрицательное")
} else {
    print("ноль")
}

# if как выражение
sign = if x > 0 { 1 } else if x < 0 { -1 } else { 0 }
```

### 6.2 Сопоставление с образцом (pattern matching)

```
match value {
    0         => print("ноль"),
    1..10     => print("от 1 до 10"),
    Ok(v)     => print("успех: " + v),
    Err(e)    => print("ошибка: " + e),
    _         => print("что-то другое"),
}
```

### 6.3 Циклы

```
# Счётный цикл
for i in 0..10 {
    print(i)
}

# Итерация по коллекции
for item in list {
    process(item)
}

# С индексом
for i, item in list.enumerate() {
    print(i, item)
}

# Цикл с условием
while cond {
    ...
}

# Бесконечный цикл
loop {
    if done { break }
}
```

### 6.4 Управление циклом

```
break         # выход из цикла
break value   # выход с возвращаемым значением (если цикл — выражение)
continue      # следующая итерация
break @label  # выход из вложенного цикла по метке
```

### 6.5 Досрочный возврат

```
return value   # явный возврат
               # последнее выражение в блоке = неявный возврат (если поддерживается)
```

- Переменная не видна до своего объявления.

```
    let x = 2     # затенение (shadowing)
```

## 16. Грамматика (EBNF)

Формальная грамматика языка. Выделить самые важные правила.

```ebnf
program       = { top_level_decl } ;

top_level_decl = fn_decl
               | type_decl
               | const_decl
               | import_stmt
               | module_stmt ;

fn_decl       = "fn" IDENT "(" [ param_list ] ")" [ "->" type ] block ;
param_list    = param { "," param } ;
param         = IDENT ":" type [ "=" expr ] ;

block         = "{" { stmt } "}" ;

stmt          = let_stmt
               | assign_stmt
               | expr_stmt
               | if_stmt
               | while_stmt
               | for_stmt
               | return_stmt ;

let_stmt      = "let" [ "mut" ] IDENT [ ":" type ] "=" expr ";" ;
assign_stmt   = lvalue assign_op expr ";" ;
assign_op     = "=" | "+=" | "-=" | "*=" | "/=" | "%=" ;

expr          = or_expr ;
or_expr       = and_expr { "or" and_expr } ;
and_expr      = cmp_expr { "and" cmp_expr } ;
cmp_expr      = add_expr { cmp_op add_expr } ;
cmp_op        = "==" | "!=" | "<" | "<=" | ">" | ">=" ;
add_expr      = mul_expr { ("+" | "-") mul_expr } ;
mul_expr      = unary_expr { ("*" | "/" | "%") unary_expr } ;
unary_expr    = [ "not" | "-" | "~" ] primary_expr ;

primary_expr  = IDENT | literal | "(" expr ")" | call_expr | index_expr ;
call_expr     = primary_expr "(" [ arg_list ] ")" ;
```

### 20.2 Числа Фибоначчи (рекурсия + итерация)

```
# Рекурсивно
fn fib(n: int) -> int {
    match n {
        0 => 0,
        1 => 1,
        _ => fib(n - 1) + fib(n - 2),
    }
}

# Итеративно
fn fib_iter(n: int) -> int {
    let mut a = 0
    let mut b = 1
    for _ in 0..n {
        a, b = b, a + b
    }
    a
}
```

### 20.3 Работа с коллекциями

```
import std.collections { List }

fn main() {
    let nums = List.of(3, 1, 4, 1, 5, 9, 2, 6)

    let evens = nums.filter(|x| x % 2 == 0)
    let doubled = evens.map(|x| x * 2)
    let total = doubled.reduce(0, |acc, x| acc + x)

    print(f"Сумма удвоенных чётных: {total}")
}
```

### 20.4 Пользовательский тип и методы

```
type Rectangle = {
    width: float,
    height: float,
}

impl Rectangle {
    fn area(self) -> float {
        self.width * self.height
    }

    fn is_square(self) -> bool {
        self.width == self.height
    }
}

fn main() {
    let r = Rectangle { width: 4.0, height: 4.0 }
    print(f"Площадь: {r.area()}, квадрат: {r.is_square()}")
}
```

### 20.5 Обработка ошибок

```
import std.io { File }

fn read_number(path: string) -> Result<int, string> {
    let content = File.read_text(path)?
    let n = int.parse(content.trim())?
    Ok(n)
}

fn main() {
    match read_number("num.txt") {
        Ok(n)  => print(f"Прочитано: {n}"),
        Err(e) => print(f"Ошибка: {e}"),
    }
}
```
